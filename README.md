# Chrome Extension Developer

"Expert in building Chrome Extensions using Manifest V3. Covers background scripts, service workers, content scripts, and cross-context communication."

## Overview

This repository preserves the original AITMPL skill definition and its published companion files.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-chrome-extension-developer-skill.git ~/.claude/skills/chrome-extension-developer
```

On Windows, use `%USERPROFILE%\.claude\skills\chrome-extension-developer` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/chrome-extension-developer` when needed.
